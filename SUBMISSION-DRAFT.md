## How the Three Challenges Work

### 1. Challenge 1 — PERCEPTION (Inspired by DocRecon)
- **Concept:** Demonstrates optical character recognition and document intelligence.
- **Visitor Action:** The user drags an interactive optical scanner (or uses keyboard `Arrow` / `End` keys) across an enterprise invoice.
- **Feedback:** As the laser sweep reaches target coordinates, bounding boxes lock onto detected data (`INV-2048-DX`, Date, Total Amount) displaying live extraction confidence telemetry (`99.8%`, `99.1%`, `99.4%`). When all 3 fields are extracted, **Key 01** unlocks with audio and visual feedback.
- **Transparency:** Explicitly labeled as a client-side simulation using predefined sample data.

### 2. Challenge 2 — REASONING (Inspired by Pathway AI)
- **Concept:** Demonstrates dynamic Retrieval-Augmented Generation for smart municipal systems.
- **Visitor Action:** The visitor investigates an urban anomaly by selecting a query (e.g., *"Why did power consumption spike in District 4?"*).
- **Feedback:** An interactive 4-stage stepper guides the visitor through `QUERY → RETRIEVAL → EVIDENCE → SYNTHESIS`. The system computes and displays semantic similarity metrics (`Cosine Sim: 0.94`), highlights retrieved municipal sensor logs, and generates a grounded response. **Key 02** unlocks.
- **Transparency:** Demonstrates the conceptual pipeline deterministically without invoking live LLM API bills.

### 3. Challenge 3 — CONNECTION (Inspired by HEFIN)
- **Concept:** Demonstrates multi-node peer-to-peer consensus in decentralized intelligence networks.
- **Visitor Action:** The user establishes connections between four distinct nodes: `Node 01: Core Ledger`, `Node 02: Inference`, `Node 03: Storage`, and `Node 04: Edge Client`.
- **Feedback:** Animated SVG dashed pulse lines trace active edges. The underlying graph algorithm evaluates connectivity and rejects self-loops and duplicate connections with visual feedback. When all 4 nodes achieve mutual reachability, consensus is reached and **Key 03** unlocks.

### Grand Finale: The Superpower Reveal
With all three keys obtained:
1. Three silver keys emerge and orbit the central chamber lock.

## AWS Services Used

### AWS Amplify Hosting
- **Continuous Deployment:** Integrated directly with GitHub repository branch `main`. Every verified commit triggers an automated build pipeline running `npm ci` and `npm run build`.
- **Global CDN Delivery:** Built artifacts (`dist/`) are distributed through Amazon CloudFront edge locations worldwide, ensuring sub-second Time-to-First-Byte (TTFB) and high availability during hackathon judging.
- **SSL / HTTPS Termination:** AWS Amplify manages and terminates custom TLS certificates, securing all user sessions.
- **Zero Ongoing Operational Cost:** Leverages serverless static hosting without unneeded paid backend compute, databases, or API gateways.

*(Note: In accordance with hackathon evaluation honesty, this submission does not claim custom AWS Lambda, Amazon Bedrock, or Amazon Cognito backend services, as the application is purposely designed as a high-performance client-side progressive web application).*

## Challenges Faced & How I Solved Them

### Challenge 1: The Portal Lighting Overexposure Glitch
- **Problem:** When visitors clicked "Enter Portal" and then navigated back to Home, the central gate remained permanently overexposed with blown-out bloom and whiteout glare.
- **Solution:** Designed a reversible state machine in `src/sections/Hero.tsx`. When transitioning back to Home, the controller resets shader uniforms, light intensity, material emissives, and camera position to their exact initial values.

### Challenge 2: Audio Autoplay vs. User Experience & Browser Policies
- **Problem:** Audio previously triggered on passive scrolling, which violated user preferences and triggered browser autoplay policy warnings.
- **Solution:** Rebuilt `KingdomAudioManager` with strict user-interaction gating and session persistence. Music remains muted by default and only plays when the user explicitly clicks the audio toggle. The user's mute choice is preserved across the entire session.

### Challenge 3: Eliminating 404 Console Errors
- **Problem:** Modern browsers automatically request `/favicon.ico`, causing a 404 console error on clean page loads.
- **Solution:** Generated a crisp SVG favicon (`public/favicon.svg`) featuring the project's crown monogram and registered it in `index.html`. Zero 404 network errors across all tested browsers.

### Challenge 4: Mobile Responsiveness & Touch Targets
- **Problem:** On 390×844 mobile viewports, the suspended hero HUD overlapped the navigation bar, and network graph nodes required precise pointer tapping.
- **Solution:** Added responsive CSS flow rules converting absolute hero elements to fluid flex layouts below the header, and expanded touch targets on graph nodes to 56px with clear active states.
